# Reference Design Notes

**Source:** [Elegance Essence - Beauty and Wellness Dashboard](https://dribbble.com/shots/24793080-Elegance-Essence-Beauty-and-Wellness-Dashboard) by Kretya Studio.

The reference uses a calm, high-key dashboard shell with a white left sidebar, lightly tinted workspace, thin cool-gray borders, generous rounded corners, and minimal shadow. Navigation is grouped by category and includes a compact search control. The header is sparse and separates workspace context from utilities and user identity.

The dashboard opens with three soft-gradient KPI cards. Its primary analytics surface is a large lavender line/area chart, while a compact right-hand panel presents near-term operational information. Typography is neutral, rounded, and highly legible with strong spacing rather than heavy decoration. Tables, inputs, filters, and list rows use low-contrast borders and small-radius controls.

For Buy & Sell Manager, these patterns should be adapted rather than copied: preserve the existing blue delivery-box logo, financial terminology, audit safeguards, contextual tooltips, all existing routes, and the public-link behavior. Use the reference for information hierarchy, grouped navigation, card treatment, analytics composition, and overall restraint. Light mode remains the default, with a user-controlled dark mode option.
